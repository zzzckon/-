BM 开户与广告账户类型：个人户、企业户、二不限怎么选

账户类型选错，是投放跑不起来最常见的原因。这篇讲清楚三者到底差在哪。

BM 到底是什么

BM 是 Meta 商务管理平台（Business Manager）的简称。它可以理解成一个资产容器：把广告账户、公共主页、像素、商品目录、支付方式都装进一个组织下面，然后给不同的人分配不同权限。

没有 BM 的时候，广告账户挂在个人账号上——个人号一封，账户和素材全没。有了 BM，资产挂在组织下，个人号只是「操作者」，换人、加人都不影响资产本身。

资产挂个人号下挂 BM 下
广告账户随个人号封禁一起失效可在组织内转移、更换操作者
公共主页迁移麻烦可授权给多人管理
像素 / 数据重建即丢失历史数据组织内共享
团队协作只能共享账号密码分级权限

个人户 / 企业户 / 二不限的区别

个人广告账户

用个人号自助开通，门槛低、开得快，但限额小、申诉通道弱，适合验证产品和少量测试。

企业广告账户（代理开户）

通过代理走企业资质开通，绑定在 BM 下。优势是限额等级更高、有代理经理可协助申诉、支持更多资产类型。行业里常说的「电商户」「游戏户」就是按用途和资质分的不同开通通道。

二不限 / 三不限

指投放限制较少的账户类型（例如不限制某些品类或投放范围）。这类账户通常价格更高，适合已经跑通模式、需要放量的团队。注意：不同代理对「二不限」的具体含义说法不完全一致，签约前要问清到底不限哪两项。

什么阶段该换企业户

  • 日消耗稳定超过个人户限额：说明模型跑通了，卡在额度上
  • 需要多人协作：投手、素材、财务要分权限
  • 需要稳定长期投放：个人号封一次就断流，成本远高于账户差价
  • 需要绑定多个主页或站点：BM 内管理更清晰

判断标准其实很简单：如果你开始因为「账户被封导致投放中断」而焦虑，就该上企业户了。

限额和稳定性怎么看

广告账户的日消耗限额不是固定的，平台会根据账户历史表现动态调整。影响它的因素包括：

  • 账户的注册时间与历史消费
  • 支付方式是否稳定（是否频繁拒付）
  • 广告内容与落地页的合规记录
  • 拒登率、投诉率

所以「买一个高限额账户」不是终点——账户买来后如果违规操作，限额照样会掉。这也是为什么素材合规和落地页质量比账户等级更值得投入。

开户前准备清单

  1. 营业执照或主体资质（代理开户通常需要）
  2. 可用的公共主页（建议提前建好，名称与业务一致）
  3. 落地页与隐私政策页（审核会看）
  4. 支付方式：信用卡 / PayPal / 对公
  5. 像素或转化 API 的接入方案
  6. 明确的目标市场与品类（影响开通通道选择）

准备齐再开户，比反复提交被拒要快得多。

常见问题

BM 被封了怎么办？

先确认是 BM 本身被限制还是下属资产被限制。BM 被限制通常可以通过申诉或由代理协助处理，但周期不确定，所以建议保留备用 BM。

个人户能转成企业户吗？

不能直接转换。企业广告账户需要按对应通道重新开通，历史数据需要通过像素和主页延续，而不是账户本身。

二不限比普通企业户贵在哪？

主要是投放限制更少、适用品类更广，因此供应更少、价格更高。购买前要确认具体不限的项目。
